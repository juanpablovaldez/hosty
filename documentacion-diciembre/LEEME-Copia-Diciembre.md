# LEEME — Copia de trabajo para la defensa de diciembre

Este directorio (`documentacion-diciembre/`) es una **copia exacta** de `documentacion-final/`
tomada el **2026-08-12**, sobre la que se documentan las funcionalidades agregadas al producto
después de la entrega original.

`documentacion-final/` queda **congelada** como el informe tal cual se entregó y se expuso: no se
edita bajo ninguna circunstancia. Toda actualización va en esta copia.

## Funcionalidades que se documentan acá

Las cuatro corresponden a líneas que el propio informe original dejó registradas como diferidas o
a defectos detectados sobre el código entregado:

| Funcionalidad | Origen en el informe original |
|---|---|
| Prevención de doble reserva | Defecto detectado sobre el código entregado (no documentado antes) |
| Reseñas y ratings | Issue #33 diferido (`post-mvp`), sección 15 |
| Notificaciones (in-app + email) | Funcionalidad nueva; no existía capa de funciones serverless |
| Pagos con Mercado Pago (sandbox) | Issue #45 diferido, sección 15 |

## Convención

Se mantienen los tres callouts del vault original (`[!todo]`, `[!note] Dato simulado`,
`[!info] Fuente`). El contenido agregado en esta copia se marca además con `[!info] Fuente` cuando
la afirmación sea verificable contra el repositorio, igual que en el informe original.
